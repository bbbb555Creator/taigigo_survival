## 🎮 ゲームの特徴

- **4つの難易度階層**: 
    - 🟢 **初級**: 日常的な基本語彙
    - 🟡 **中級**: 社会生活で使われる語彙
    - 🔴 **上級**: 抽象概念や難読熟語
    - 🔥 **地獄級**: 業界用語・専門知識・マニアックな対比
- **全国ランキング**: スコアを登録して、全国の猛者と競い合おう！
- **PWA対応**: スマホのホーム画面に追加すれば、いつでもすぐプレイ可能。
- **🆕 v4.0の新機能（2026.11.17）**:
    - 📖 **まちがい帳**: 間違えた問題が自動で貯まる復習モード。正解すると1問ずつ「卒業」！
    - 📤 **結果シェア**: X / Threads / Instagramへ、結果テキストをそのまま投稿できる
    - 🔥 **デイリーストリーク**: デイリーの連続プレイ記録を表示
    - ✨ **レア称号＆季節称号**: 低確率で特別な称号が出現（12月はクリスマス称号も）
    - 📝 **間違いレポート**: ゲームオーバー時に自分の答えと「引っかけポイント」を表示
